# Body・Shift（ダイエット記録アプリ）

体重と食べたものを1日1ページで記録して、目標まであと何kgかとグラフが自動で更新される、PC用（16:9）のWebアプリです。

## 使い方

1. 「目標を変更する」で目標の体重を入れる
2. アイコンと好きな画像は、それぞれの右下にある「変更」ボタンから自分の画像に差し替えられる
3. カレンダーの日付をクリック → その日の体重（朝・昼・夜）と食べたもの・カロリーを記入
4. 「保存してホームへ」を押すと、「あと ○○ kg」とグラフが自動で更新される

いちばん後に入れた体重（夜→昼→朝の順）が、その日の記録としてグラフに使われます。

## データについて

記録・目標・画像は、使っている人のブラウザの中だけに保存されます。サーバーには送られません。
ブラウザの「閲覧データの削除」でサイトデータを消すと、記録も消えます。

## ファイル

- `index.html` … これ1つだけで動きます（イラストも埋め込み済み）

ブラウザで開いて、F11キーで全画面にすると画面ぴったりに表示されます。
